# Controle Financeiro Residencial

## Descrição

Aplicação para gerenciamento de gastos residenciais, permitindo o controle de despesas, organização financeira e visualização de informações de forma simples.

O sistema é dividido em frontend e backend, com foco em usabilidade e organização dos dados.

---

## Tecnologias 

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui

### Backend

* .NET

---

## Funcionalidades

* Cadastro de despesas
* Listagem de gastos
* Organização por categorias
* Visualização de totais

---

## Como executar o frontend

```bash
npm install
npm run dev
```

A aplicação será iniciada em:
http://localhost:5173

---

## Estrutura do projeto

* `src/` → componentes e lógica da aplicação
* `public/` → arquivos estáticos
